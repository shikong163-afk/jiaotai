# 一瓷一品 · 绞胎纹生成

当阳峪绞胎瓷（河南 · 焦作修武）主题的纹样生成页。单文件、零依赖、可离线打开。

两种泥叠起来，绞，揉，切一刀——这一刀，只出这一条纹。

## 这是什么

按绞胎的工艺写的纹样算法：**叠合 → 折叠/扭转（绞揉）→ 切片**，不是随机噪声。

- 三种绞法：折纹 / 旋纹 / 编织
- 五种泥色 + 从照片取色（k-means 取双色，压回泥的色域）
- 三个参数：绞揉次数、扭转角度、纹样密度
- 瓶身预览：把纹贴到玉壶春瓶轮廓，叠柱面明暗
- 导出 1080×1440 海报（带编号、说明、赛项信息）

## 与赛项的关系

2026 年河南省职业院校技能大赛 · 新闻传播赛道，主题短片《泥里的算法》里的互动环节（镜 30—32）：
观众扫码 → 生成自己的纹 → 存海报 → 导流到当阳峪打卡 / 研学。
